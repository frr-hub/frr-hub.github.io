GET与POST的区别

GET的语义是获取服务器资源，查询参数拼接在URL中，属于请求行的一部分。GET会受到URL长度限制，浏览器默认缓存GET请求，请求记录会保存到书签和浏览历史，具备幂等性，多次请求不会新增业务数据。

POST用于向服务器提交数据，数据放置在请求体中。HTTP协议本身没有对请求体设置长度限制，数据以流的形式读取。POST默认不会被浏览器缓存，不具备幂等性，重复提交表单可能造成重复操作。

安全误区：HTTP协议下GET与POST均为明文传输。POST仅把数据藏在请求体，抓包工具依旧可以读取内容，想要加密通信必须使用HTTPS。

week1-HTTP抓包

HTTP抓包（Hexo本地博客 localhost:4000）

1. 基础信息（General）

  • Request URL：http://localhost:4000/
  • Request Method：GET （获取网页资源）
  • Status Code：200 OK 请求成功

2. Response Headers 响应头（服务器→浏览器）

服务器告诉浏览器返回的数据类型，返回text/html网页。
X-Powered-By: Hexo 标识网站程序为Hexo。

3. Request Headers 请求头（浏览器→服务器）

浏览器向Hexo服务器自我介绍，说明需求：

  • Host: localhost:4000：访问的目标主机与端口
  • Accept-Language: zh-CN：优先中文内容
  • Accept：浏览器支持接收的文件类型
  • Connection: keep-alive：保持连接，复用通道

HTTP完整流程

  1. 浏览器和Hexo建立TCP连接
  2. 浏览器发送GET请求报文（请求头）
  3. Hexo收到请求，读取请求头，返回HTML网页（响应头+网页代码）
  4. 浏览器解析HTML，自动发起多条新GET请求，下载CSS、JS、图片等资源
  5. 全部资源下载完成，浏览器渲染页面展示

前端三件套与前端页面构成

前端三件套

  1. HTML：页面骨架，定义页面上有哪些元素（文字、图片、按钮等）。
  2. CSS：页面样式，控制颜色、大小、排版，美化页面。
  3. JavaScript(JS)：页面交互，实现点击、弹窗、表单校验等动态功能。

前端页面的构成

前端页面由 HTML、CSS、JavaScript（JS）三件套共同构成，在浏览器中渲染展示：

  1. 浏览器通过HTTP请求，从服务器获取HTML文件。
  2. 解析HTML，搭建页面的基础结构，生成页面骨架。
  3. 加载CSS文件，为页面元素设置颜色、布局、大小等样式，完成美化。
  4. 执行JavaScript代码，实现点击、表单校验等交互功能。

HTML是页面的基础骨架，CSS负责外观，JS负责交互，三者配合，最终渲染成完整网页。
