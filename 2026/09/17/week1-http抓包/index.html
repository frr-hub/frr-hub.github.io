week1-HTTP抓包

HTTP抓包（Hexo本地博客 localhost:4000）

1. 基础信息（General）

  • Request URL：http://localhost:4000/
  • Request Method：GET （获取网页资源）
  • Status Code：200 OK 请求成功

2. Response Headers 响应头（服务器→浏览器）

服务器告诉浏览器返回的数据类型，返回text/html网页。
X-Powered-By: Hexo 标识网站程序为Hexo。

3. Request Headers 请求头（浏览器→服务器）

浏览器向Hexo服务器自我介绍，说明需求：

  • Host: localhost:4000：访问的目标主机与端口
  • Accept-Language: zh-CN：优先中文内容
  • Accept：浏览器支持接收的文件类型
  • Connection: keep-alive：保持连接，复用通道

HTTP完整流程

  1. 浏览器和Hexo建立TCP连接
  2. 浏览器发送GET请求报文（请求头）
  3. Hexo收到请求，读取请求头，返回HTML网页（响应头+网页代码）
  4. 浏览器解析HTML，自动发起多条新GET请求，下载CSS、JS、图片等资源
  5. 全部资源下载完成，浏览器渲染页面展示
